# 智能仓储 AGV 3D 路径规划仿真

基于 **Ursina / Panda3D** 的 3D 机器人路径规划仿真。一台小型四轮工业 AGV
在现代化智能仓储测试区中，使用真实搜索算法从起点自动前往目标点，
可实时增删障碍物、重设目标，并在路线被阻断时自动重新规划。

## 运行

```bash
pip install -r requirements.txt
python3 agv_sim.py
```

> 需要图形界面（OpenGL）。字体文件 `cjk.otf`（中英文）需与脚本在同一目录。

无窗口自测（自动步进、中途投放障碍验证自动重规划，不弹窗）：

```bash
AGV_SMOKE=1400 python3 agv_sim.py
```

## 操作

| 输入 | 功能 |
|---|---|
| 鼠标左键 | 依当前模式：设置目标点 / 添加障碍 / 删除障碍 |
| `Tab` 或 `1` `2` `3` | 切换 目标点 / 添加障碍 / 删除障碍 模式 |
| `Q` | 切换要添加的障碍类型（货架 / 集装箱 / 围栏 / 设备箱） |
| `空格` | 暂停 / 继续 |
| `R` | 重新开始（机器人回到起点，清空轨迹） |
| `N` | 随机生成场景 |
| `Esc` | 退出 |
| 鼠标右键拖动 / 滚轮 / 中键 | 旋转视角 / 缩放 / 平移 |

- **目标点模式**：点击空闲地面即可把目标移到该处；点击障碍物无效。
- **添加障碍模式**：鼠标处显示半透明绿色预览（红色表示与其他障碍/机器人/边界重叠，
  此时无法放置），左键放置，机器人立即重规划。
- **删除障碍模式**：点击任意障碍物即可移除。

## 真实算法（无固定路线、无预设动画）

### 路径规划 —— `planner.py`（与渲染解耦，可单独测试）

1. **栅格化**：把 40×30 m 场地划分为 0.5 m 均匀栅格，障碍物按机器人外接半径
   膨胀（并保留场地安全边界），得到二值阻塞图。
2. **A\***：8 邻接搜索，octile 距离作一致启发函数；斜向移动要求两个正交邻居均空闲，
   禁止贴角穿越；带 `closed` 表与二叉堆开表。
3. **视线平滑**：用 Amanatides–Woo **DDA 精确栅格遍历**做线段碰撞检测，
   贪心"拉线"删除多余拐点，得到短而平滑的折线路径。
4. **目标吸附**：目标点落在障碍物内时，用 BFS 找最近的空闲可达栅格。

### 运动与避障 —— `agv_sim.py`

- 差速底盘运动学：最大速度 3.2 m/s、加减速度、最大角速度 120°/s，
  大角度偏差时原地转向；车轮按 `v/r` 真实滚动。
- 每帧对前方 1.4 m 的**规划路径线段**做碰撞采样，发现被新障碍阻断即重新 A\*（带节流）。
- 位移积分前再做一次栅格碰撞保险，保证**绝不穿模**。
- 终点消费半径 / 到达容差 / 末段线性减速，使机器人精确停在目标点。

HUD 实时显示：状态、速度、当前路径长度、剩余距离、重新规划次数、模式、障碍数量。

## 文件

- `agv_sim.py` —— 3D 场景、AGV 模型、交互、运动控制与可视化。
