# 仓储 AGV 3D 路径规划仿真

基于 **Ursina + Panda3D** 的可直接运行 3D 机器人路径规划仿真。现代化智能仓储测试区，
小型四轮工业 AGV 从起点自主导航至目标点，全程使用真实算法，无固定路线、无预设动画。

## 运行

```bash
pip install ursina pillow
python3 agv_sim.py              # 正常运行
python3 agv_sim.py --windowed   # 1400×900 窗口模式（4K 全屏卡顿/某些合成器下推荐）
python3 agv_sim.py --selftest   # 无头算法自检（不弹窗）
python3 agv_sim.py --smoke      # 自动冒烟测试（约 12 秒退出）
python3 agv_sim.py --shot       # 自动截图（生成 agv_shot0/1.png）
```

Linux 下中文界面使用 Noto Sans CJK（`/usr/share/fonts/opentype/noto/`）。

## 真实算法（非动画、非预设）

| 模块 | 实现 |
|---|---|
| 环境建模 | 40×30 占据栅格，障碍按底盘半径做 1 格膨胀（corridor clearance） |
| 全局规划 | **A\***：八邻域、octile 一致启发式、二叉堆 open-list、禁止斜穿障碍墙角 |
| 路径平滑 | **LOS 贪心弦切**（line-of-sight 0.25 m 采样碰撞检测），把栅格折线压成最少航点 |
| 局部跟踪 | **纯追踪 Pure Pursuit**：投影到最近路径段，沿弧长取 1.0 m 前视点，差速运动学（最大线速度 2.4 m/s、最大角速度 200°/s，转角自动减速） |
| 在线重规划 | 每 0.4 s 沿规划走廊做碰撞校验；被新增障碍阻断或机器人偏离路径 >1 m 时自动重跑 A* |
| 编辑安全 | 放置障碍后立即做连通性校验，封死路径则自动回滚；起点/机器人/目标位置禁止放置 |
| 场景生成 | 随机货架巷道 + 集装箱 + 设备箱 + 围栏，每放一个障碍都验证可达性，保证场景始终有解 |

## 场景与机器人

- 浅灰网格地面（程序生成纹理，每 5 m 粗线）、四周安全围栏
- 障碍：三层横梁式**货架**（带彩色货箱）、**海运集装箱**（瓦楞+随机涂装）、
  **设备箱/充电桩**、四米**安全围栏**，尺寸各不相同
- AGV：低矮底盘、四个可见车轮（随行驶转动）、顶部旋转激光雷达扫描头、
  车顶状态灯（绿=行进、橙=受阻闪烁、青=转向/规划）、前照灯

## 可视化

- **青色方块**：当前规划路径航点；**橙色轨迹**：实际行驶轨迹
- 红色目标光柱 + 绿色起点标记
- HUD：状态（自主行进/转向/原地转向/受阻重规划/已到达）、路径长度、剩余距离、
  行驶里程、实时速度、重新规划次数、暂停状态

## 交互

| 操作 | 功能 |
|---|---|
| 左键点击/拖拽 | 当前模式：设目标 / 连续加障碍 / 连续删障碍 |
| 右键拖拽 / 滚轮 | 环绕视角（相机跟随机器人）/ 缩放 |
| `1` | 目标点模式（点击空闲地面重设目标） |
| `2` | 放置货架 |
| `3` | 循环切换 集装箱 → 设备箱 → 围栏 |
| `4` | 删除障碍（点击障碍本体） |
| `F` | 旋转待放置障碍 0°/90° |
| `空格` | 暂停 / 继续（暂停时机器人与规划全部冻结） |
| `R` | 机器人回到起点重新开始（保留场景） |
| `N` | 随机生成全新场景 |

放置时有绿色/红色地面预览：红=该位置与障碍重叠或越界。

## 文件

- `agv_sim.py` — 主程序（单文件，含 GridPlanner / AGVSimulation / 自检）
- `interact_test.py` — 动态障碍自动化交互测试（运行中放置障碍，断言重规划与绕行）
- `agv_shot*.png` / `interact_shot.png` — 验证截图
